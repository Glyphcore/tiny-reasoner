## Pitfalls
- Plain rank-one route explodes ppl (readout unconstrained off the judge position): use tr/calib.py.
- Arithmetic unmerge is not bit exact: revert from backup.
- Run one eval process at a time on 4 threads (a heldout run is about 9 minutes).
